# AxiomLab site

Svelte 5 / SvelteKit 3 / Tailwind 4 site for AxiomLab. Static build, deployed to
<https://kerneldroid.github.io/axiomlab/>.

## Development

```bash
npm install
npm run sync     # copies axiomlab.js (as ESM), benchmarks.json, results.json from the repo root
npm run dev      # http://localhost:5173/axiomlab/
npm run check    # svelte-check
npm run build    # static output in ./build
npm run preview
```

`BASE_PATH` overrides the deploy base (default `/axiomlab`).

## Deployment

`.github/workflows/deploy-site.yml` builds this site on every push to `main` that
touches `site/` (or the shared JS/benchmark data) and publishes `site/build` to
the `gh-pages` branch of `kerneldroid/axiomlab`. That repository serves
<https://kerneldroid.github.io/axiomlab/>. The workflow authenticates with a
write-scoped deploy key stored as `PAGES_DEPLOY_KEY` in `sysv86/axiomlab`.


## Fonts

`src/lib/assets/fonts/` contains Latin-only subsets of Google Sans Flex and Roboto Flex (166 KB + 79 KB) generated with `fonttools varLib.instancer` + `pyftsubset`. The Fontsource packages remain dev dependencies so the subsets can be regenerated; the build does not ship the full multi-script faces.

## Theme

The Material 3 role structure is generated by AxiomLab itself, not by Material
Color Utilities / HCT. `src/lib/m3/scheme.ts` converts the seed to AxiomLab LCh
and samples every role at an M3 tone with a role-specific chroma factor, then
gamut-maps through AxiomLab's own mapping. The seed is Color A in the
Playground; there is no separate theme color picker.

## Data

`src/lib/data/benchmarks.json` and `src/lib/data/results.json` are produced by
the repository scripts:

```bash
python3 optimize_and_verify.py
python3 benchmark_helmlab.py
cd site && npm run sync
```
